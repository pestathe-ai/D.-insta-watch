# Chiave di firma (sviluppo)

`app.jks` è una chiave **pubblica di sviluppo**, con la password in chiaro in `password.txt`.
Serve solo perché ogni nuova versione dell'APK si installi sopra la precedente
(installazione manuale, "sideloading").

**Non usarla per il Play Store**: chiunque può leggerla da questo repository.
